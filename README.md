# 기업 설명회 일정 만들기

Chrome 또는 Edge에서 안내받은 주소를 엽니다. 현재 이 컴퓨터의 확인용 주소는 http://127.0.0.1:8002/project/ 입니다. 화면이 열리지 않으면 실행 담당자에게 확인해 주세요.

1. **엑셀 파일 선택**에서 매니저 신청 명단을 선택합니다.
2. **기업시간표 선택**에서 준비된 `private/기업시간표.xlsx`를 선택합니다. 명단에 기업시간표가 함께 들어 있으면 따로 선택하지 않아도 됩니다.
3. **기업시간표 확인·수정**을 눌러 운영 시간을 확인하고, 바꿀 시간은 체크하거나 해제합니다. 운영할 시간은 원하는 개수만큼 선택합니다. 오전·오후 구분과 다른 시간을 체크하면 경고가 나오지만, 배정은 체크한 시간으로 진행합니다.
   엑셀에 기업을 추가하거나 운영 시간의 O 표시를 바꾼 경우, **기업시간표 선택**에서 해당 파일을 다시 선택하면 반영됩니다.
4. 수정한 시간표를 보관하려면 **수정한 시간표 엑셀 저장**을 누릅니다. 원본 엑셀은 자동으로 변경되지 않습니다.
5. **일정 만들기**를 누르고, 완료되면 **결과 파일 받기**를 누릅니다.

받은 압축파일을 풀면 매니저별 일정 이미지, 기업별 참석자 이미지, 결과 엑셀이 들어 있습니다. 모든 기업은 타임당 최대 **10명**입니다.

연습할 때는 `private/dummy_managers_and_companies.xlsx`를 선택하세요. 가상 매니저 200명과 기업시간표가 함께 들어 있습니다.

화면을 닫기 전에 필요한 결과와 수정한 시간표를 저장해 주세요. `private` 폴더의 명단과 시간표는 외부에 공개하지 마세요.
